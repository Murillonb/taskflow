# TaskFlow

TaskFlow is a simple task management app built from scratch to help users organize, track, and manage their daily tasks.<br>
The project was created as part of my front-end development learning path, focusing on core JavaScript concepts, DOM manipulation, event handling, and browser data persistence.

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks by status: open or completed
- Automatically display the task creation date
- Save tasks in the browser using Local Storage
- Add clickable links inside task descriptions
- Responsive layout for different screen sizes

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Local Storage
- GitHub

## What I Learned

While building this project, I practiced:

- Creating a project from scratch
- Manipulating the DOM with JavaScript
- Handling user interactions with events
- Working with arrays and dynamic rendering
- Persisting data in the browser with Local Storage
- Building a responsive user interface with HTML and CSS
